Retrieval Augmented Generation is an AI architecture
that combines information retrieval with large language models.

RAG retrieves relevant information from external knowledge
sources before generating an answer.

The RAG architecture consists of document ingestion,
text chunking, embedding generation, vector storage,
retrieval, and response generation.

ChromaDB is a vector database used to store and retrieve
vector embeddings.

Ollama allows developers to run large language models
locally on their computers.
